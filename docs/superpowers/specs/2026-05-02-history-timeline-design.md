# 历史缩略图时间线设计

**日期**: 2026-05-02
**范围**: 回溯窗口状态变化，支持历史截图查看

## 目标

为 WinScope 添加历史缩略图时间线功能，允许用户回溯查看窗口的历史状态变化。适用于监控游戏挂机、长时间任务进度等场景。

## 需求

### 功能需求

1. **历史存储**
   - 为每个监控窗口存储最近 N 张截图（默认 20 张）
   - 存储格式：缩略图 PNG + 时间戳
   - 存储位置：内存（不持久化到磁盘）

2. **时间线 UI**
   - 在窗口卡片下方显示时间线滑块
   - 滑块位置对应历史截图索引
   - 拖动滑块显示对应时间点的截图

3. **回放控制**
   - 点击时间线上的时间点，显示该时刻的截图
   - 暂停实时捕获，显示历史截图
   - 点击"实时"按钮恢复实时捕获

### 非功能需求

- 内存占用：< 50MB（20 张截图 × 5 个窗口）
- 时间线交互延迟：< 100ms
- 不影响实时捕获性能

## 架构

### 数据结构

```rust
// 历史截图条目
struct HistoryEntry {
    timestamp: u64,        // Unix 时间戳（毫秒）
    image: String,         // Base64 编码的 PNG
}

// 窗口历史（按时间倒序）
struct WindowHistory {
    entries: VecDeque<HistoryEntry>,
    max_entries: usize,    // 默认 20
}
```

### 前端状态

```typescript
// 历史截图
interface HistoryEntry {
  timestamp: number;
  image: string;
}

// 窗口历史状态
const [histories, setHistories] = useState<Map<string, HistoryEntry[]>>(new Map());
const [viewingHistory, setViewingHistory] = useState<string | null>(null); // 窗口标题
const [historyIndex, setHistoryIndex] = useState<number>(-1); // -1 = 实时
```

### 数据流

1. **捕获更新**
   - Rust 后端捕获新帧
   - 前端收到 `capture-update` 事件
   - 将截图添加到对应窗口的历史记录
   - 如果历史记录超过最大数量，删除最旧的条目

2. **时间线交互**
   - 用户拖动时间线滑块
   - 前端更新 `historyIndex`
   - 显示对应时间点的截图
   - 暂停实时捕获更新

3. **恢复实时**
   - 用户点击"实时"按钮
   - 前端重置 `historyIndex` 为 -1
   - 恢复实时捕获更新

## UI 设计

### 时间线组件

```
┌─────────────────────────────────────────────┐
│  Window Title                    [实时] [×] │
├─────────────────────────────────────────────┤
│                                             │
│          截图预览区域                        │
│                                             │
├─────────────────────────────────────────────┤
│  ○───●─────────────────────────────○       │
│  12:00  12:05  12:10  12:15  12:20         │
└─────────────────────────────────────────────┘
```

- 顶部：窗口标题 + 实时按钮 + 关闭按钮
- 中部：截图预览（全尺寸）
- 底部：时间线滑块 + 时间标签

### 交互流程

1. **进入历史模式**
   - 用户点击窗口卡片上的"历史"按钮
   - 弹出历史预览窗口
   - 显示最新截图，时间线滑块在最右端

2. **浏览历史**
   - 拖动时间线滑块
   - 实时更新截图预览
   - 显示对应时间点的时间标签

3. **恢复实时**
   - 点击"实时"按钮
   - 时间线滑块回到最右端
   - 恢复实时截图更新

4. **关闭历史**
   - 点击"×"按钮
   - 关闭历史预览窗口
   - 恢复实时截图更新

## 性能优化

1. **内存管理**
   - 使用 `VecDeque` 自动清理旧条目
   - 限制最大条目数（默认 20）
   - 历史截图使用压缩后的缩略图（480px 宽）

2. **渲染优化**
   - 时间线滑块使用 CSS 变量控制位置
   - 避免频繁的 React 重渲染
   - 使用 `requestAnimationFrame` 更新滑块位置

3. **存储优化**
   - 不持久化到磁盘
   - 应用退出时自动释放内存
   - 窗口关闭时清理对应历史记录
