# 系统托盘设计

**日期**: 2026-05-02
**范围**: 最小化到系统托盘，托盘菜单控制

## 目标

为 WinScope 添加系统托盘功能，允许应用最小化到托盘继续运行，通过托盘菜单快速控制应用。

## 需求

### 功能需求

1. **最小化到托盘**
   - 点击关闭按钮时，应用最小化到托盘而非退出
   - 双击托盘图标恢复窗口
   - 托盘图标显示应用状态（监控中/暂停）

2. **托盘菜单**
   - 显示/隐藏主窗口
   - 暂停/恢复截图
   - 置顶切换
   - 退出应用

3. **状态指示**
   - 托盘图标显示tooltip（监控窗口数量）
   - 不同状态使用不同图标（可选）

### 非功能需求

- 托盘图标清晰可见（16x16 或 32x32）
- 菜单响应延迟 < 100ms
- 不影响应用启动速度

## 架构

### Tauri 托盘插件

使用 `tauri-plugin-tray` 插件实现系统托盘功能。

```rust
// Cargo.toml
[dependencies]
tauri-plugin-tray = "2"
```

### 前端状态

```typescript
// 托盘相关状态
const [isMinimizedToTray, setIsMinimizedToTray] = useState(false);
```

### 数据流

1. **最小化到托盘**
   - 用户点击关闭按钮
   - 前端调用 `invoke("minimize_to_tray")`
   - Rust 后端隐藏主窗口
   - 托盘图标显示

2. **恢复窗口**
   - 用户双击托盘图标
   - Rust 后端显示主窗口
   - 前端恢复状态

3. **托盘菜单操作**
   - 用户点击托盘菜单项
   - Rust 后端执行对应操作
   - 前端更新状态
